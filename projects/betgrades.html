BetGrades

Sports Betting Tracker & Analytics

Next.jsReactNode.jsPostgreSQL
Project image coming soon

BetGrades is a full-stack web app for tracking sports betting picks, odds, and ROI over time. It pulls pick data through the X API and web scraping, then stores everything in a PostgreSQL database managed with Prisma.

Overview

The dashboard surfaces win rate, profit/loss, and streak trends so users can see what's working over time. This project is still in progress — more detail and screenshots will be added soon.
